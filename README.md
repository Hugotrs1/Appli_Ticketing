# Appli Ticketing

Application de bureau de gestion de tickets de support informatique, réalisée en formation.

## Fonctionnalités

- Inscription et connexion, avec un espace utilisateur et un espace administrateur
- Création de tickets avec un niveau de criticité
- Suivi du statut des tickets et réponse de l'administrateur
- Notifications par mail et sur Telegram

## Stack

C# / .NET 8, WPF (MVVM), Dapper, SQL Server, MailKit

## Lancer

Ouvrir `Appli_Ticketing.sln` dans Visual Studio, renseigner la chaîne de connexion SQL Server dans `App.Config`, puis lancer le projet.
